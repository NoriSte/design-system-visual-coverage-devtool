# React + TypeScript + Vite

This example provides a minimal setup for design system in Vite project.

## Running the example

Build the design system:
```bash
# in the repo root
yarn
yarn build
```

Run example:
```bash
yarn
yarn dev
```

## Development

Run the design system build in watch mode:
```bash
# in the repo root
yarn
yarn dev
```

Run example:
```bash
yarn
yarn dev
```
